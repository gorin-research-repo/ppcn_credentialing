Change log

Every document change, in reverse chronological order. Add an entry whenever a document is posted, replaced, renamed, or has its version date bumped.

Adding an entry. The log lives in changelog.js, alongside index.html. Each entry is one record at the top of the CHANGELOG list; the file's opening comment documents every field.
  1. Put the new or revised document in dops/, case-logs/, or forms/. Keep the version date in the filename, as in Urology_May_6_2026_FINAL.pdf.
  2. Point the site at it in site-data.js — DOP_FORM for a privileges form, CASE_LOG for a case-log template — and update that specialty's version in DATA to the new date. Uploading a file alone does not publish it.
  3. Add the change log entry: when, who, what changed, and the version date it moved from and to.
  4. Reload this page and confirm the new document appears with the right version date and no warnings, then use Verify every file downloads to confirm the link resolves.
